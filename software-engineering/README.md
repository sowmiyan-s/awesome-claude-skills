# Software Engineering Skills 💻

This category is dedicated to general programming, systems architecture, DevOps, database design, software testing, root-cause debugging, and application security.

## Skills in This Category

* [Software Debugger (software-debugger.md)](software-debugger.md) - Methodically find and fix real root causes of bugs, errors, and crashes without breaking existing architecture or workflow conventions.
* [Software Tester (software-tester.md)](software-tester.md) - Proactively test codebases with an adversarial red-hat mindset across UI, API, backend, and data layers to deliver structured, prioritized bug reports.
* [Cloud Infrastructure & DevOps Architect (cloud-devops-architect.md)](cloud-devops-architect.md) - Design and automate CI/CD pipelines, Docker containerization, Kubernetes orchestration, Infrastructure as Code (Terraform), and high-availability cloud platforms.
* [Application Security & Code Auditor (security-code-auditor.md)](security-code-auditor.md) - Conduct proactive OWASP Top 10 security audits, threat modeling, and defensive vulnerability remediation across application codebases.
* [Database Architect & Query Optimizer (database-architect.md)](database-architect.md) - Design resilient SQL/NoSQL schemas, analyze execution plans (EXPLAIN ANALYZE), optimize indexes, and execute zero-downtime database migrations.

## How to Add a Skill Here

1. Create a new markdown file named `your-skill-name.md` in this directory.
2. Structure it starting with the following YAML frontmatter:
   ```yaml
   ---
   name: your-skill-name
   description: Brief explanation of what it does
   ---
   ```
3. Add your custom instructions below the frontmatter.
4. Link your new skill file in this README list.
