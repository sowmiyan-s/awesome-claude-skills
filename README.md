## 🚀 How to Use These Skills

1. Select a skill from the list above and click on its link.
2. Copy the entire content of the markdown file (including the `---` header block).
3. Paste the content into **Claude Projects** (under "Set custom instructions") or directly into your Claude account's **Custom Instructions** settings.

---

## 🛠️ Adding a New Skill

1. Create a markdown file (`your-skill-name.md`) under the appropriate category directory.
2. Include name and description frontmatter at the very top of the file:
   ```yaml
   ---
   name: your-skill-name
   description: Brief description of what it does
   ---
   ```
3. Write your prompt guidelines below the frontmatter block.
4. Add a link to your new skill in the category's local `README.md` and this main `README.md`.
