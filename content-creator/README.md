# Content Creation Skills ✍️

This category is dedicated to blogging, social media planning, newsletter writing, video script editing, and creative storytelling skills.

## Skills in This Category

* [Blogger Baby (blogger-baby.md)](blogger-baby.md) - Turn rough notes, outlines, or abstract ideas into engaging, publish-ready technical and non-technical articles.

## How to Add a Skill Here

1. Create a new markdown file named `your-skill-name.md` in this directory.
2. Structure it starting with the following YAML frontmatter:
   ```yaml
   ---
   name: your-skill-name
   description: Brief explanation of what it does
   ---
   ```
3. Add your custom instructions below the frontmatter.
4. Link your new skill file in this README list.
