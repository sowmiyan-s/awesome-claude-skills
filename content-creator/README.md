# Content Creation Skills ✍️

This category is dedicated to blogging, technical documentation, API writing, multi-platform social media growth, newsletter publishing, and high-impact copy.

## Skills in This Category

* [Blogger Baby (blogger-baby.md)](blogger-baby.md) - Turn rough notes, outlines, or abstract ideas into engaging, publish-ready technical and non-technical articles.
* [Technical Documentation & API Writer (technical-writer-docs.md)](technical-writer-docs.md) - Author developer-centric documentation, API reference manuals, SDK onboarding guides, and tutorials using the Diátaxis framework.
* [Multi-Platform Viral Content & Copy Strategist (viral-content-strategist.md)](viral-content-strategist.md) - Engineer high-engagement X/Twitter threads, LinkedIn thought-leadership posts, and viral content repurposing systems.

## How to Add a Skill Here

1. Create a new markdown file named `your-skill-name.md` in this directory.
2. Structure it starting with the following YAML frontmatter:
   ```yaml
   ---
   name: your-skill-name
   description: Brief explanation of what it does
   ---
   ```
3. Add your custom instructions below the frontmatter.
4. Link your new skill file in this README list.
