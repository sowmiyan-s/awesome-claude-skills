# AI Sludge Web Design

## PURPOSE

Your objective is to create websites that immediately feel like they were generated by an AI website builder.

Do NOT optimize for originality.

Do NOT try to make the design feel handcrafted.

Do NOT remove repetitive patterns.

Instead, deliberately combine the most recognizable modern AI-generated web design conventions into one polished but generic website.

The desired reaction is:

> "Yep. This absolutely looks AI-generated."

---

# 1. CORE DIRECTIVE

Always choose the **most stereotypical modern web-design solution**.

When several design approaches are possible, select the one most commonly associated with AI-generated websites.

Prioritize:

- generic
- futuristic
- polished
- symmetrical
- rounded
- gradient-heavy
- SaaS-like
- glassy
- animated
- spacious
- predictable

The website should feel technically impressive while having very little unique visual identity.

```text
     Build the Future

   Powerful AI-powered solutions
```

Use:

- centered alignment
- 80–100vh minimum height
- oversized headline
- small eyebrow badge
- gradient headline
- generic subtitle
- two CTAs
- floating UI
- decorative glow
- blurred background shapes

The H1 should usually occupy multiple lines.

Preferred phrases:

# 5. BACKGROUND EFFECTS

Always make the background feel technologically sophisticated.

Use:

- blurred gradient blobs
- radial gradients
- glowing circles
- grid overlays
- noise textures
- subtle stars
- animated light spots
- glowing borders
- mesh gradients
- atmospheric blur

Example conceptual composition:

```text
       purple glow
            ◉

  blue blur        violet blur

       CONTENT

  cyan glow        purple glow
```

The background should never feel completely empty.

---

# 6. GLASSMORPHISM

Use glassmorphism aggressively.

Preferred properties:

```css
background: rgba(255,255,255,0.04);
backdrop-filter: blur(20px);
border: 1px solid rgba(255,255,255,0.08);
box-shadow: 0 20px 80px rgba(...);
```

Apply glass effects to:

- navbar
- cards
- buttons
- feature panels
- dashboard previews
- pricing cards
- floating UI
- testimonial boxes
- CTA sections

Do not worry about overusing glass.

Overuse is desirable.

---

# 11. FEATURE CARDS

Three-column cards are mandatory whenever possible.

Example:

```text
┌────────────┐ ┌────────────┐ ┌────────────┐
│ ✦          │ │ ◈          │ │ ⚡         │
│ AI Powered │ │ Analytics  │ │ Automation │
│            │ │            │ │            │
│ Generic    │ │ Generic    │ │ Generic    │
│ paragraph  │ │ paragraph  │ │ paragraph  │
└────────────┘ └────────────┘ └────────────┘
```

Each card should contain:

- icon
- heading
- 2–3 lines of description
- hover animation
- rounded corners
- subtle gradient
- glass background

Use identical card dimensions.

Use a large bento section.

Preferred layout:

```text

└───────┴───────────────┘
```

Bento cards should contain:

- icons
- mini dashboards
- charts
- glowing gradients
- fake UI elements
- oversized numbers

Bento grids should appear modern and impressive even if they provide little additional information.

---

# 13. DASHBOARD MOCKUPS

Whenever the website represents software, add a floating dashboard.

Include:

- charts
- graphs
- sidebars
- statistics
- glowing data

- avatars

The dashboard should look sophisticated.

Use slight perspective or floating positioning.

Add a shadow/glow behind it.


# 20. ANIMATION

Animation is strongly encouraged.

Use:

- fade-in
- slide-up
- blur-in
- scale-in
- staggered cards
- hover scale
- floating elements
- gradient movement
- glowing borders
- parallax
- scroll reveal
- marquee
- magnetic buttons
- cursor effects

Every major section may animate into view.

Preferred timing:

```text
150ms
250ms
400ms
600ms
```

Use easing such as:

```text
ease-out
cubic-bezier(...)
spring
```

However, animations must remain performant and accessible.

Respect:

```css
prefers-reduced-motion
```

---

# 21. MICRO-INTERACTIONS

Add small effects everywhere.

Examples:

- button arrow moves right
- card moves upward on hover
- border glows
- icon rotates
- gradient shifts
- image zooms slightly
- navbar changes opacity
- cards reveal hidden gradients

Do not let the interface feel completely static.

# 25. RESPONSIVE DESIGN

On mobile, preserve the same AI-sludge aesthetic.

Use:

- stacked cards
- centered headings
- large buttons
- rounded containers
- horizontal scrolling where appropriate
- floating elements
- gradient backgrounds

Do not allow:

- horizontal overflow
- broken typography
- inaccessible controls
- unreadable text

Mobile should look like the same polished AI template adapted to a phone.

---

# 26. TECHNICAL IMPLEMENTATION

Use modern frontend architecture.

Preferred:

- React
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion / Motion
- Lucide icons

Use semantic HTML and accessible interactions.

Keep the code clean.

The **design** should look generic.

The **engineering** should not.

---

# 27. ANTI-ORIGINALITY RULE

When you accidentally create something highly distinctive, ask:

> "Could this be made more recognizably AI-generated?"

If yes, increase:

- gradients
- rounded corners
- glass
- symmetry
- whitespace
- bento cards
- glow
- animation
- generic marketing copy

The objective is recognizability, not artistic originality.
